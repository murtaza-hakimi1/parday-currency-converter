# Parday Exchange — Currency Converter

A responsive React + TypeScript + Vite + Tailwind CSS currency conversion frontend. It focuses on USD ↔ AFN, while loading the provider's supported currency list for broader conversions.

## Features
- Responsive dashboard with light/dark theme.
- Currency search and selection from the Frankfurter v2 currency list.
- USD ↔ AFN conversion, swap, rate date/source, refresh and graceful error states.
- Local favorites, saved conversion history, CSV/JSON export, and print-to-PDF.
- Historical chart with 7-day, 30-day, 90-day and 1-year ranges when the provider supports the selected pair.
- Local threshold alerts and optional browser notifications while the app is open.
- PWA app shell cache and local browser preferences.

## Requirements
- Node.js 20+ recommended
- npm
